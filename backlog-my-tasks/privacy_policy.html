Privacy Policy

最終更新：2026年4月7日

🛡️

基本方針

「Backlog My Tasks」（以下、本拡張機能）は、ユーザーのプライバシーを尊重し、個人情報の適切な保護に努めます。

✅ 外部送信なし — すべてのデータは端末内で完結します
📋

収集する情報

本拡張機能が収集・保存する情報は以下のみです：

  • Backlog スペース URL：設定画面で入力したURL（chrome.storage.sync に保存）
  • Backlog API キー：設定画面で入力したAPIキー（chrome.storage.sync に保存）

また、以下の情報をローカルストレージ（chrome.storage.local）に一時保存します（端末外には送信しません）：

  • 取得したタスクデータのキャッシュ
  • ユーザーが入力したローカルメモ
  • ピン留め・通知履歴などの設定
🎯

情報の利用目的

収集した情報は以下の目的のみに使用します：

  • ユーザーが設定したBacklogスペースのAPIへのアクセス
  • ログインユーザーに割り当てられたタスクの取得・表示
🚫

第三者への提供

収集した情報は、ユーザーが設定したBacklogのAPIエンドポイント以外のいかなる第三者にも送信・提供しません。すべてのデータ処理はユーザーのブラウザ内で完結します。

✅ 外部送信なし
🌐

外部サービスへの通信

本拡張機能はユーザーが設定したBacklogスペース（例：https://yourspace.backlog.com）のAPIにのみ通信します。アナリティクス・広告・トラッキングサービスへの通信は一切行いません。

💻

リモートコード

本拡張機能はリモートコードを実行しません。すべてのコードは拡張機能パッケージ内にバンドルされており、Chrome ウェブストアによって審査・署名されています。

🔒 Chrome Web Store 審査済み
💾

データの保存場所

すべてのデータはユーザーのブラウザ内（Chromeストレージ）にのみ保存されます。本拡張機能の開発者がユーザーのデータにアクセスすることはできません。

ブラウザのデータを消去することで、保存されたデータをいつでも削除できます。

👤

未成年者について

本拡張機能は、Backlogを利用する業務ユーザーを対象としたビジネスツールです。未成年者の使用を意図したものではありません。

📝

ポリシーの変更

本プライバシーポリシーは予告なく改訂される場合があります。重要な変更がある場合は、拡張機能のアップデートリリースノートでお知らせします。最新版は常に本ページに掲載されます。

📬

お問い合わせ

本プライバシーポリシーに関するご質問は、Chrome ウェブストアの拡張機能ページよりお問い合わせください。

Overview

"Backlog My Tasks" (the "Extension") is committed to protecting your privacy and handling your personal information with care.

✅ No external uploads — all data stays on your device
📋

Information We Collect

The Extension collects and stores only the following:

  • Backlog Space URL: The URL you enter in settings (stored in chrome.storage.sync)
  • Backlog API Key: The API key you enter in settings (stored in chrome.storage.sync)

The following is temporarily stored in local storage (chrome.storage.local) and never leaves your device:

  • Cached task data retrieved from Backlog
  • Local notes you enter
  • Settings such as pinned items and notification history
🎯

How We Use Your Information

Collected information is used solely for:

  • Accessing the Backlog space API you configured
  • Retrieving and displaying tasks assigned to you
🚫

Third Parties

Your information is never sold, shared, or disclosed to any third party other than the Backlog API endpoint you configured. All data processing occurs entirely within your browser.

✅ No external data transmission
🌐

External Communications

The Extension communicates only with the Backlog space API you configured (e.g., https://yourspace.backlog.com). No analytics, advertising, or tracking services are used.

💻

Remote Code

The Extension does not execute remote code. All code is bundled within the extension package and has been reviewed and signed by the Chrome Web Store.

🔒 Chrome Web Store verified
💾

Data Storage

All data is stored only within your browser (Chrome storage). The developer of this Extension has no access to your data.

You can delete all stored data at any time by clearing your browser data.

👤

Minors

The Extension is a business tool intended for Backlog users in a professional context. It is not designed for or directed at minors.

📝

Policy Changes

This Privacy Policy may be updated at any time. Significant changes will be announced in the extension's release notes. The latest version will always be available on this page.

📬

Contact

For questions about this Privacy Policy, please reach out via the extension's page on the Chrome Web Store.

基本方針

「Backlog My Tasks」（以下簡稱「本擴充功能」）尊重使用者的隱私，並致力於妥善保護個人資訊。

✅ 不對外傳送 — 所有資料僅在裝置內處理
📋

收集的資訊

本擴充功能收集與儲存的資訊僅限以下項目：

  • Backlog 空間 URL：在設定畫面輸入的 URL（儲存於 chrome.storage.sync）
  • Backlog API 金鑰：在設定畫面輸入的 API 金鑰（儲存於 chrome.storage.sync）

以下資訊會暫時儲存於本機儲存空間（chrome.storage.local），不會傳送至裝置外部：

  • 取得的工作資料快取
  • 使用者輸入的本機備忘錄
  • 釘選、通知紀錄等設定
🎯

資訊的使用目的

收集的資訊僅用於以下目的：

  • 存取使用者設定的 Backlog 空間 API
  • 取得並顯示指派給登入使用者的工作
🚫

提供給第三方

收集的資訊不會出售、共享或提供給使用者設定的 Backlog API 端點以外的任何第三方。所有資料處理均在瀏覽器內完成。

✅ 無外部資料傳輸
🌐

與外部服務的通訊

本擴充功能僅與使用者設定的 Backlog 空間（例：https://yourspace.backlog.com）的 API 進行通訊。不使用任何分析、廣告或追蹤服務。

💻

遠端程式碼

本擴充功能不執行遠端程式碼。所有程式碼均已封裝於擴充功能套件中，並經過 Chrome 線上應用程式商店的審查與簽署。

🔒 Chrome 線上應用程式商店已審查
💾

資料儲存位置

所有資料僅儲存於使用者的瀏覽器（Chrome 儲存空間）中。本擴充功能的開發者無法存取使用者的資料。

清除瀏覽器資料即可隨時刪除所有已儲存的資料。

👤

未成年人

本擴充功能是專為使用 Backlog 的業務人員設計的商業工具，並非針對未成年人所設計或提供。

📝

政策變更

本隱私權政策得隨時更新。重大變更將於擴充功能的更新版本說明中公告。最新版本將持續發布於本頁面。

📬

聯絡方式

如對本隱私權政策有任何疑問，請透過 Chrome 線上應用程式商店的擴充功能頁面與我們聯繫。
